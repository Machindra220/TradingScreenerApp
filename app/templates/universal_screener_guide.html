1. What Is the Universal Screener?

The Universal Screener is a configurable multi-filter pipeline that combines every metric computed across all screeners in this app into a single unified interface. Instead of running five separate screeners and manually cross-referencing results, you configure a set of filters once — enable the ones relevant to your strategy, set thresholds, add optional MA rules — and run a single scan that applies all conditions simultaneously.

All conditions use AND logic — a stock must pass every enabled filter to appear in results. MA rules (if any) are also ANDed with the fixed filters. There is no silent failure: if a metric can't be computed (e.g. insufficient data), the stock is excluded and counted in the "scanned" total but not the "passed" total.

4. Moving Average Rules

In addition to the fixed filters, you can add any number of custom MA conditions using the rule builder at the bottom of the filter panel. These use the same engine as the dedicated MA Screener and are combined with AND logic against the fixed filters.

{% for op, meaning, nla, use in [ ('CROSS ABOVE','Previous bar: left ≤ right. Current bar: left < right.','✅ Only reads today + yesterday','Fresh bearish signal — trend breakdown'), ('IS ABOVE','left > right at today\'s close.','✅ Only reads today','Trend alignment — stock in uptrend structure'), ('IS BELOW','left < right at today\'s close.','✅ Only reads today','Bearish alignment — avoid for long-only'), ('IS RISING','MA[today] > MA[N days ago].','✅ Only reads historical values','Slope confirmation — MA pointing up'), ('IS FALLING','MA[today] < MA[N days ago].','✅ Only reads historical values','Bearish slope — MA pointing down'), ] %} {% endfor %}
Operator Meaning No Look-Ahead? Typical use
{{ op }} {{ meaning }} {{ nla }} {{ use }}
Crossover vs Alignment: "EMA 10 CROSSED ABOVE EMA 20" and "EMA 10 IS ABOVE EMA 20" are different signals. The crossover is a fresh event — it happened recently (within the lookback window). The alignment is a current state — EMA 10 is above EMA 20 right now, regardless of when it crossed. Both are valid depending on your strategy; choose based on whether you want to catch the moment of change or confirm an established trend.
